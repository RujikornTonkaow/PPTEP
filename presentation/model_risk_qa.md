# Model Risk Q&A (ตอบสั้นๆ ตอนสอบปากเปล่า)

ใช้ตอบคำถามเรื่องความเสี่ยงของโมเดล Q2 Bull/Bear (Dataiku · LightGBM) ซึ่งตรงกับบทวิเคราะห์ข้อ 6 บน dashboard

## 1. Overfitting

- **คืออะไร:** โมเดลจำข้อมูลที่ใช้ train ได้แม่นมาก แต่พอเจอข้อมูลใหม่กลับทายพลาด
- **ของเรา:** AUC ชุด train 1.000 กับชุด test 0.998 แทบเท่ากัน แต่ไม่ได้แปลว่าโมเดลดีจริง เพราะติดปัญหา data leakage (ข้อ 2)
- **ป้องกันยังไง:** ดูผลบนชุด test ที่โมเดลไม่เคยเห็น และเลือกโมเดลที่ไม่ซับซ้อนเกินไป

## 2. Data leakage

- **คืออะไร:** มีข้อมูลที่ "บอกคำตอบ" หลุดเข้าไปตอนโมเดลเรียน
- **ของเรามี 2 จุด:**
  - label Bull/Bear คำนวณจาก `PTTEP_Close` เทียบ SMA50 แต่เราก็ใส่ `PTTEP_Close` เป็น input ด้วย โมเดลจึงเกือบรู้คำตอบ (เป็นปัจจัยอันดับ 1 ที่ 28%)
  - Dataiku แบ่ง train/test แบบสุ่ม วันที่ติดกันซึ่งราคาแทบเท่ากันจึงอยู่ทั้งสองฝั่ง
- **ผล:** ROC-AUC 0.998 สูงเกินจริง
- **แก้ยังไง:** เอา `PTTEP_Close` ออกจาก input และแบ่งข้อมูลตามเวลา (time-based split)

## 3. Look-ahead bias

- **คืออะไร:** ใช้ข้อมูลที่ในชีวิตจริง ณ เวลานั้นยังไม่มี
- **ของเรา:** S&P 500 ของวันเดียวกันยังไม่มีตอนตลาดไทยปิด เพราะตลาดสหรัฐเปิดทีหลัง และโมเดลใช้ข้อมูลวันนี้ทายสภาวะวันนี้ จึงเป็นการจำแนกสภาวะปัจจุบัน ไม่ใช่การทายอนาคต
- **แก้ยังไง:** ใช้ข้อมูลถึงเมื่อวาน (lag 1 วัน) ทายวันพรุ่งนี้หรือล่วงหน้าหลายวัน

## 4. การเติมข้อมูล (Imputation)

- **คืออะไร:** บางวันไม่มีข้อมูลพันธบัตรไทย เพราะวันหยุดไม่ตรงกับตลาดอื่น เราจึงเติมค่าด้วยการ interpolate (ประมาณจากวันก่อนและวันหลัง)
- **ทำอะไร:** สร้างคอลัมน์ `Thailand_1Y_Yield_Pct_Imputed` และ `Thailand_10Y_Yield_Pct_Imputed` (True/False) บอกว่าแถวไหนเป็นค่าที่เติม เพื่อความโปร่งใส แต่ไม่ได้ใช้สองคอลัมน์นี้เป็น input ของโมเดลใน Dataiku (ทั้ง Q1 และ Q2) โมเดลจึงไม่ได้เรียนจากธงการเติมข้อมูล
- **ข้อระวัง:** การ interpolate ใช้ค่าของวันถัดไปด้วย ซึ่งเป็น look-ahead เล็กน้อย

## 5. ความสัมพันธ์เปลี่ยนไป (Regime / Concept drift)

- **คืออะไร:** ความสัมพันธ์ระหว่างปัจจัยกับราคาหุ้นไม่คงที่ เช่น บางช่วง PTTEP ขยับตามน้ำมันมาก บางช่วงขยับตามดอกเบี้ยมากกว่า
- **ผล:** โมเดลที่ train ด้วยข้อมูลอดีตอาจใช้กับอนาคตไม่ได้
- **ทำอะไร:** ดู correlation 60 วันที่เปลี่ยนไปได้บน dashboard ควร train ใหม่เป็นระยะ และเลิกใช้โมเดลถ้า AUC บนข้อมูลใหม่ลดลงใกล้ 0.5 (ระดับเดียวกับการเดาสุ่ม)

## ถ้าอาจารย์ถามว่า "ทำไม AUC ได้ 0.998"

ตอบว่าเป็นเพราะ data leakage จากการใส่ราคา PTTEP เป็น input และการแบ่งข้อมูลแบบสุ่ม ทีมรู้ปัญหานี้และเขียนเปิดเผยไว้ในข้อ 6 ของ dashboard แล้ว คำตอบนี้แสดงว่าเราเข้าใจ model risk จะได้คะแนนดีกว่าอ้างว่าโมเดลแม่น 99.8%
